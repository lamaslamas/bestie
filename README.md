# BESTIE

Wildlife, landscape and reportage photography by Andrea Lamas.

## Aggiungere una foto
1. Esporta da Lightroom: lato lungo 2000 px, JPEG qualità 80, sRGB, **Remove Location Info** attivo.
2. Rinomina il file in modo descrittivo (es. `grey-heron-salento.jpg`) e mettilo in `img/`.
3. Aggiungi una riga in `photos.js` con sezione, titolo, luogo, larghezza/altezza in pixel e una breve descrizione (alt).
4. Carica i file su GitHub: il sito si aggiorna da solo in un paio di minuti.

La prima foto di ogni sezione in `photos.js` è quella in evidenza.
